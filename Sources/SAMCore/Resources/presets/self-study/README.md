# Self-study

**Promise:** A self-directed learning plan — a few tracks (systems, algorithms,
networking) broken into stages, worked through a flip loop where solving problems
is the proof, with projects as the thing you actually build.

**Label:** **Structural template — no date-specific content.** The tracks, stages, topics, problemsets,
resources and projects below are generic examples that show what each kind is
for. Nothing here is a dated claim: no exam dates, syllabi, cutoffs, weightages
or session counts. Session records carry minutes but no dates, and the plan has
no calendar — add your own when you start.

## Shape

- **Tracks** (`course`) group the work; `kind` is `systems`, `algorithms`,
  `networking`, `math`, `tools` or `other`. Three example tracks ship.
- **Stages** (`unit`) are ordered steps inside a track; **topics** are the work
  itself, each with an estimate in minutes and a kind (`read`, `watch`,
  `practice`, `build`, `write`, `revise`).
- **Topics are trackable on the `flip` pipeline**: `learned → proved →
  anchored`. A `watch` topic must be proved with at least **two solved
  problems** before it can be anchored — a prompt alone is not evidence.
- **Problemsets** are the other trackable kind, on the `progress` pipeline
  (`started → midway → done`), with a `pct(solved, total)` formula and no stored
  percentage.
- **Projects**, **resources**, **assessments**, **sessions**, **notes** and
  **milestones** round out the plan. `session` and `note` are marked
  `"private": true`, so they are excluded from a shared profile.
- **Scheduler:** this preset pins **`sm2`** (the seed preset uses the fixed
  ladder), so it exercises a second scheduler; switching back is a JSON write.

## Screens

Today, Plan, Tracks, Practice, Projects, Reviews, Progress, Library, Notes —
every navigation entry points at a declared screen view, and every type has at
least one view and one example record.
