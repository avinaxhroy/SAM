# Blank — SAM's empty plan

**Label: structural template — the schema, and nothing else.**

This is the preset the first run creates: the §3.2 starter schema — the twelve
kinds, their views, the flip-proof study method, the fixed review ladder and the
shell's destinations — with **no records at all**. Zero records is a real state
(§3.7's empty modes): the app's Today says the plan is empty and offers the
course door, rather than showing a demonstration the student did not author.

## What it is not

- **Not a term, and not an example.** There is no `content/records/` here; the
  student's first course is theirs to add. The presets that ship beside this one
  (`jee`, `neet`, `cbse11-pcm`, `university-term`, `self-study`, `language`) are
  the filled-in starts: the first run's one press makes *this* plan, and a
  filled-in start is asked for by name — `plan.new` with its preset id, or
  `SAM plan.new --name <name> --preset <id>` on the terminal.
- **Not a smaller schema.** `content/{types,views,rules,shell,appearance}.json`
  are the seed's own documents, byte for byte: every kind, view, rule and
  destination exists from the first launch, so nothing has to be added later by
  migration.
